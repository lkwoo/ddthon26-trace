# Business Rules — U3 Web Viewer

> U3 규칙은 SSR 위임 어댑터로서의 계약을 규정한다. 상위 원칙: "로직 미보유·위임·결정적 SSR·서버 미중단·최소 의존성". (U2 BR-M* 를 이어 BR-W* 로 번호화)

## 위임/경계 규칙
- **BR-W1 (로직 미보유)**: U3는 검색/추출/병합 로직을 구현하지 않는다. U1 `KnowledgeReadService`에 위임한다(읽기 전용).
- **BR-W2 (읽기 전용)**: 웹 뷰어는 지식 베이스를 변경하지 않는다. 편집/업데이트는 에이전트 `update_note`(U2) 경로로만.
- **BR-W3 (포트 의존)**: 렌더러/라우터는 U1 읽기 서비스 인터페이스에만 결합. 구현 주입은 U4 조립 루트에서.

## 라우트/입력 규칙
- **BR-W4 (미존재 404)**: 미인제스천/미존재 `{target}` 또는 미지원 경로는 404 HTML 페이지를 반환하고 **서버는 중단되지 않는다**(US-H4/H2).
- **BR-W5 (engine-first 고지)**: summary 페이지는 엔진 자동 생성 콘텐츠가 재동기화 시 소스 기준으로 재생성됨을 사용자에게 명시(배너/배지)하고, 에이전트 노트는 별도 출처로 구분 표시한다(US-H4 AC-2, FR-C1).

## 렌더/출력 규칙
- **BR-W6 (HTML 안전)**: 모든 동적 텍스트는 `html.escape` 후 삽입. Markdown 렌더러는 허용 요소(heading/para/list/code/inline-code)만 생성하며 원문 HTML을 통과시키지 않는다(XSS 방지 — 최소 위생).
- **BR-W7 (결정적 렌더)**: 동일 U1 읽기 결과 → 동일 HTML(순수 함수 렌더러). 렌더는 외부/네트워크/LLM 호출 없이 로컬에서만(NFR-C3, FR-H5).
- **BR-W8 (예외 격리)**: 핸들러는 하위 예외를 포착해 404/안내 페이지로 변환. 어떤 단일 요청도 서버 프로세스를 종료시키지 않는다.

## 운영 규칙
- **BR-W9 (표면 계측)**: 각 라우트 핸들러는 `measure("web.<view>")`로 elapsed_ms를 로깅한다. 응답 내용에 영향 없음(US-N1).
- **BR-W10 (로컬·최소 의존)**: 서버는 stdlib `http.server`로 로컬 기동하며 외부 서비스/웹 프레임워크에 의존하지 않는다(FR-H5, NFR-E1). `[web]` extra는 비어 있다.
