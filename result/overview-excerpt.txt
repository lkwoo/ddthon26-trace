# 프로젝트 온보딩 맵

Start with the REST entry point: `petclinic/src/main/java/org/springframework/samples/petclinic/owner/OwnerRestController.java` is a @RestController that exposes the Owner Registration endpoint. It builds and validates an `Owner` (`owner/Owner.java`), whose fields — including `telephone` — map onto the persistence schema in `resources/db/schema.sql` and the documented contract in `resources/openapi.yaml`. `owner/OwnerRegistrationTests.java` exercises this flow end to end. As a newcomer, read OwnerRestController first, then Owner, then confirm the field constraints against schema.sql and openapi.yaml — note these two sources disagree on telephone length, so treat that constraint as low-confidence until confirmed.

## 진입점

- **OwnerRestController** (`petclinic/src/main/java/org/springframework/samples/petclinic/owner/OwnerRestController.java`) — rest_controller: @RestController/@Controller 애노테이션
- **PostMapping** (`petclinic/src/main/java/org/springframework/samples/petclinic/owner/OwnerRestController.java`) — rest_endpoint: @PostMapping 라우트
- **RequestMapping "/api/owners"** (`petclinic/src/main/java/org/springframework/samples/petclinic/owner/OwnerRestController.java`) — rest_endpoint: @RequestMapping 라우트
- **__main__** (`tools/gen_requirements_pdf.py`) — main: if __name__ == '__main__' 블록
