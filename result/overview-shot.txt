# 프로젝트 온보딩 맵

Start with the REST entry point: OwnerRestController.java is a @RestController that
exposes the Owner Registration endpoint. It builds and validates an Owner (Owner.java),
whose fields — including telephone — map onto the persistence schema in schema.sql and the
documented contract in openapi.yaml. As a newcomer, read OwnerRestController first, then
Owner, then confirm the field constraints — note schema.sql and openapi.yaml disagree on
telephone length, so treat that constraint as low-confidence until confirmed.

## 진입점
- OwnerRestController (owner/OwnerRestController.java) — rest_controller
- PostMapping (owner/OwnerRestController.java) — rest_endpoint
- RequestMapping "/api/owners" (owner/OwnerRestController.java) — rest_endpoint
